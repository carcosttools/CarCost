CarCostPrivacy

PRIVACY

Simple by design.

CarCost does not require an account, password, payment card or banking information.

Calculator inputs

The calculator runs in your browser. The values you enter are not sent to a CarCost database. Shareable result links can contain values from the calculator in the URL, so only share a result link if you are comfortable sharing those values.

Hosting

CarCost is currently hosted on GitHub Pages. GitHub may process technical information needed to serve the website according to its own policies.

Analytics and advertising

CarCost currently does not use its own analytics, advertising trackers or advertising cookies. If this changes, this page should be updated before those features are enabled.

Feedback

If you choose to submit feedback through GitHub, the information you provide there is handled through GitHub.
